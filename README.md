# CyberSafe Awareness Website

**Student name:** Digari Mahavirkumar Parsotambhai 
**Course/Bootcamp:** Cybersecurity Bootcamp  
**Project type:** Cyber safety awareness website

## Overview
CyberSafe is a simple educational website that explains phishing awareness, strong passwords, OTP safety, safe browsing, privacy, and common online scams.

## Features
- Responsive layout for phone and desktop screens
- Cyber safety information cards
- Interactive cyber safety checklist
- Three-question quiz with score and restart
- No external libraries, tracking, or personal-data collection

## How to run
1. Download or clone this project.
2. Open `index.html` in a modern web browser.
3. Scroll through the tips, use the checklist, and try the quiz.

## Files
- `index.html` — website structure, styling, and quiz logic
- `requirements.txt` — dependency information
- `project_report.pdf` — project report

## Limitations
This is an awareness and learning project, not a security scanner. It does not detect malware or inspect links.
